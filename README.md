# Chat Bubble

**简体中文** | [English](README.en.md)

Windows 透明悬浮聊天应用，当前公开测试版本为 0.16.1。史莱姆可拖动贴边、点击展开、点击外部缩回。紧凑单条输入框提供手动截图键，Codex CLI 支持原生图片消息及外部新消息同步；保留自动保存、原生会话、重启续聊、流式聊天、停止/重试、托盘和草稿恢复。

## 直接运行

先从托盘退出旧版，再打开 release/ChatBubble-0.16.1-win32-x64/ChatBubble.exe，或双击项目根目录的“启动 ChatBubble.lnk”。便携包需要保留整个文件夹，不需要 Node.js。旧包与已配置的聊天目录保留。0.13.x没有更新模块，0.14.1存在内置下载问题，首次均需手动运行新版；之后可在设置→版本内更新。它是未签名的 Windows x64 便携测试版本。首次下载请前往[GitHub Releases](https://github.com/SeXon007/ChatBubble/releases)，下载完整ZIP并解压，运行其中的ChatBubble.exe。源码构建的输出位于release目录；已配置的快捷方式可继续使用。

首次使用：右键系统托盘图标 → 设置，选择 API / Codex CLI；Claude CLI 已移除。API 服务商提供 DeepSeek、Kimi、智谱 GLM 和自定义；选择预设会填入官方地址，填写并保存对应 API Key 后可从模型下拉选择。DeepSeek/Kimi 尝试读取服务模型目录，读取失败时保留少量常用候选；智谱当前提供官方常用候选，候选不等于账户权限已验证。模型仍可手动填写，自定义地址需支持 Chat Completions 的 SSE 流式协议，也可填写完整 `/chat/completions` 地址。模型目录读取只请求元数据，“检查连接”才发送测试消息。

下拉和开关修改后立即自动保存，文本停止输入约 350ms 或离开输入框后保存；密钥在结束编辑后加密保存。无保存按钮，关闭窗口前会处理最后一次输入。切换服务地址不会把旧 Key 带到新服务；需填写对应 Key。当前仍保存一组服务地址绑定的凭据，未增加多服务账号管理。

输入框截图图标：Codex CLI和支持识图的API模型可用，点击才截图，成功后自动把图片复制到系统剪贴板，并随下一条消息发送。剪贴板写入失败会提示，已保存、已附上的截图仍可发送。设置 → 聊天 → 截图范围可选择“前台窗口”或“整个屏幕”，自动保存；默认保持原前台窗口模式。整个屏幕包括鼠标所在显示器的桌面、多个窗口及实际遮挡关系、任务栏，使用Windows原生机制排除ChatBubble自身的消息、输入框、桌宠和设置，并显示它们底下的画面；截图时不隐藏界面或改变焦点。完整排除要求Windows 10 2004或更新版本，其他遵守该机制的截图/录屏工具也会跳过ChatBubble；不拼接所有显示器；图像保留原始分辨率PNG，不再将最长边缩到1920px；保存、剪贴板和模型输入均使用原图。原有单图16 MB和原生1600万像素限制保留。切换范围解除未发送旧图关联，不会自动截图。展开、拖动、长按松开及普通文字发送不截图。已截图时再次点击可打开双图标浮层，左侧重截、右侧移除，悬停显示说明。发送或移除后解除本次关联，收起再展开保留草稿关联，重启不恢复未发送图；已保存文件不自动删除。失败只显示“未能读取画面”，重截失败不复用旧图。旧“自动读屏”设置已移除，其保存值不再触发捕获。收起状态下的史莱姆不激活应用，打开聊天框后才取得输入焦点。

API截图：DeepSeek可选deepseek-flash，Kimi可选kimi-k3.1-pro/kimi-k3，智谱可选新增的GLM-4.6V-Flash识图候选；其他已核对型号见需求文档§8.1。未确认的官方模型禁用截图并提示型号，自定义API可尝试标准image_url输入，能力由服务端决定，不自动换模型。截图以图片内容随消息发送到当前服务。重试复用原图；成功历史内的图片在预算内随追问重发，可能增加图片输入用量。单图上限16 MB，最多8图、总原图24 MB；旧图缺失或超预算会明确标记，当前图无法读取则报错，不静默丢图。更换服务、模型或截图范围会解除未发送关联。

设置顶部为五个等宽选项卡：连接、聊天、外观、桌宠、版本，选中项以下划线标识。连接页配置服务/CLI 与模型；聊天页管理消息区高度、截图范围、存储位置和历史；外观页调整字号、字体颜色和投影；桌宠页直接调整形象与运动参数。版本页显示真实应用版本，提供正常宽度的“检查更新”和“更新”按钮；更新来源为GitHub Releases；点击检查后发现新版，可下载、核对SHA-256并准备到独立版本目录，完成后点击“重启并更新”。退出前保存聊天和设置，保留旧包及聊天目录；保存失败取消重启，启动失败尝试恢复旧版。不会在打开设置时自动联网。点击切换，无折叠展开，支持左右键及 Home/End 切换；各页沿用自动保存，切换不丢弃正在编辑的内容。每次打开设置恢复默认内容宽420px；切换选项卡也恢复默认宽度，并按当前内容调整高度、限制在显示器工作区内。仍可拖动边框或最大化，手调尺寸只在当前页面保留，切页或重开时重新适配。

“检查连接”仅在连接页显示，先保存当前有效修改，再发送一条简短测试消息，不携带历史，会使用账户额度。切换服务地址后，旧密钥不会发送给新地址；请输入对应密钥。密钥不回显，可点清除。无效输入保留原有效配置并显示提示，不会另建第二套生效配置。

## 操作

- Enter发送，Shift+Enter换行；中文选词中不会发送。设置→聊天→消息区高度可在120–800px间调节，默认380px，自动保存并在重启后恢复；实际显示仍受屏幕可用空间限制。输入框固定42px高，长文字内部滚动，不显示滚动条、内边框或拉伸角标。
- 回复过程中圆形按钮变为停止按钮；未完成回答下方可重试，复用原用户消息。
- 点击史莱姆，它会伸展为输入框；点击其他软件或按 Esc，缩回打开前的位置，草稿和生成任务继续保留。
- 拖动史莱姆到屏幕工作区边缘，按住时仍是圆球，松手后慢慢压低、摊开，整团保持可见；四边都可以贴合。
- 待机眨眼、拖动睁大、接触时眯眼，静置约 12 秒休息；移动鼠标或点击唤醒。
- 从0.16.1起，桌宠默认保留跳跃、拉伸回弹、贴边与展开形变的软弹动效，不随Windows系统动画开关关闭；已有桌宠参数保留，无需调整系统设置。
- 右键托盘打开设置，“桌宠”内可调颜色、身体/眼睛大小、黏稠感、贴边范围、眼睛跟随和输入框长度，修改自动保存。右键单击史莱姆跳跃躲避，按住右键拖动则原地拉伸，松手回弹；右键不弹菜单。托盘菜单提供开始新对话、设置和退出，单击托盘切换史莱姆显示/隐藏。透明空白区域不挡住其他软件。
- 托盘菜单“开始新对话”会直接归档当前对话并清除待发送截图关联；“退出”保存并终止程序。
- 完成配置后的下次启动默认收起。再次运行会唤起已有实例。

## 保存与限制

历史按 Codex CLI、DeepSeek、Kimi、智谱及不同自定义 API 地址隔离。切换来源先归档当前消息与草稿，再新开空白对话；同一家服务切换模型不新开。同源历史才允许列表展示、预览、恢复和续聊。旧记录没有可靠来源时原样保留在本地文件夹，提示未分类，不猜测后混入某一家历史；仅可由完整原生轮次标记确认的旧Codex记录按Codex归类。旧Claude配置在升级启动时保留归档并转为API待配置，不自动发送消息。

新用户默认在程序文件夹内 `chat/` 保存当前会话、草稿和设置（state.json），`sessions/` 保存归档。已有自定义目录继续使用；旧默认目录的数据安全复制到新默认目录并保留原件。设置中可查看、更改聊天目录。历史支持预览、恢复及打开当前或所选历史的 Codex 原生会话；恢复前先归档当前对话。文件使用串行原子替换与 .bak 备份；损坏数据保留，无法恢复时停止启动。

Codex CLI模式由手动截图键按所选范围读取画面，发送问题才附图；不显示图片、缩略图或成功弹窗，只在按钮上显示待发送状态。只读屏幕，不操作电脑。所有成功保存的截图直接写入`chat/attachments/`，移除按钮仅解除待发送关联；未发送、收起、重截、重启和退出均不自动删除文件，由用户手动清理。删除被历史引用的文件后，回看原图或重试可能找不到文件。旧`screenshot/`普通文件会校验迁入`attachments/`，不覆盖重名附件，迁空后移除旧目录；自建子目录或链接保留。其他应用兼容性和真实视频/游戏流畅度仍需实测。

设置支持将聊天存储切换到空文件夹：先复制并逐文件校验，再切换；原目录作为静态备份保留，不同步更新。`storage-location.json` 记录当前目录，仍放在默认应用数据目录，`credentials.json` 和 CLI 工作目录也留在那里。自定义目录丢失或不可用时停止启动；请先恢复文件夹/磁盘连接，不要用空数据覆盖原记录。

credentials.json 只存系统加密后的密钥并绑定服务地址。Windows DPAPI 保护不等同于抵御同一登录用户下的其他程序；不要将用户数据目录作为便携包内容分发。

设置不再提供上下文选项。Codex 使用原生会话管理窗口和压缩，本地单条输入保护为 200,000 字符，不是模型 token 窗口。API 暂沿用 12,000 字符输入上限和已有字符预算，未将未知服务宣称为支持最大窗口；字符不等于 token。API 首段和无数据等待超时为 60 秒。

支持段落、列表、粗体、行内代码、代码块和 HTTP(S) 链接；HTML 只显示为文本。Codex CLI及视觉API模型支持发送手动截图，ChatBubble不渲染图片。不支持工具调用、自动操作电脑、语音和并行多会话。

API 协议证据来自本机 HTTP 测试服务；Codex CLI 已通过本机登录状态收到真实模型回复。Claude CLI 已移除，旧文件保持可读。真实中文输入法、托盘手动点击、多屏和全部 DPI 条件仍需人工验收。用户当前反馈的界面问题按要求留待最终集中调整。

## 开发与验证

需要 Node.js 22.23 或更新的受支持版本。

```powershell
npm ci
npm start
npm test
npm run smoke
npm run test:restart
npm run package
```

首次运行可能下载 Electron。如果网络依赖 HTTP_PROXY / HTTPS_PROXY，可在当前 PowerShell 会话设置 `$env:NODE_USE_ENV_PROXY='1'` 后重试。

构建输出为 dist/。打包脚本不覆盖已有同版本目录。smoke 使用隔离临时数据和本机测试服务，不读取真实密钥或调用云端模型；test:restart 使用两个独立进程核对恢复和单实例。正常 Windows 权限下执行文件替换/原生测试，受限沙箱可能禁止 rename。

## 本地 CLI 方式

设置页会从 PATH、常见用户安装目录及 npm 包入口定位 Codex 的原生 .exe，检查版本能力；不会全盘扫描，也不会自动安装或替你登录。可以重新检测或手动选择路径。npm 的 .cmd / .ps1 入口会解析为对应原生程序，不执行用户输入的任意 shell 命令。

- Codex：在终端完成 `codex login` 后可使用；支持沿用 CLI 的 ChatGPT 订阅登录或 API 登录。是否有额度以该账户为准。
- Codex 模型可从本机缓存列表选择或手填；模型和推理强度修改后自动保存，并显式传入 CLI。
- 模型可留空使用 CLI 默认；此时实际型号未确认，界面会明确标注。缓存列表不保证该账户一定有权限，模型窗口是缓存元数据，不是实时剩余上下文。需要验证账户可用性时主动点击连接检查。
- 本地 CLI 通常仍请求云端模型，不等于离线，也不保证免费。ChatBubble 不读取、复制或展示 CLI 的登录令牌。
- Codex 经 App Server 创建原生会话，只发送当前新消息；保存会话 ID，重启后续接。对话写入同一本地 Codex 数据环境（CODEX_HOME，默认用户目录下 .codex），不受 ChatBubble 的本地归档迁移影响。旧版本地记录不会自动导入 Codex。连接检查使用临时会话，避免污染历史。
- Codex CLI 连接下，在设置 → 聊天 → 历史对话中点击“在 Codex 中查看当前对话”；选择历史记录后按钮对应“所选对话”，直接打开原生会话，无需恢复或替换当前对话。没有原生会话 ID 时保留禁用入口并说明原因。展开时只读刷新已完成的新消息，发送前再次核对并同步；保留草稿，不回退外部消息。另一端占用时需在那边关闭会话再重试；外部回退/编辑与同时生成不在支持范围。不保证跨电脑、Windows/WSL 或不同 CODEX_HOME 自动同步。
- 独立工作目录、通过 stdin 传消息、关闭 shell 拼接。Codex 沿用 CLI 登录及连接配置，以启动覆盖关闭命令/插件/浏览器/记忆等能力，并逐个禁用 MCP，使用只读权限；不改全局配置。MCP 名称暂仅支持字母、数字、下划线和连字符，其他名称会拒绝连接。
- 需要原生 CLI 版本支持这些限制；旧版本会提示更新。停止按钮只结束本次 CLI 进程树；不会退出你已有的终端或其他会话。
- CLI 无数据超时为 120 秒。取消、失败和额度不足均保留消息，允许在原来源重试；切换服务会另开对话，不把旧请求转发到另一家。

官方参考：[Codex 身份认证](https://learn.chatgpt.com/docs/auth)、[Codex App Server](https://learn.chatgpt.com/docs/app-server)。
